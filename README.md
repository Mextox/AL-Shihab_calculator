# 🚗 حاسبة تمويل السيارات الاحترافية

تطبيق ويب احترافي لحساب تمويل السيارات مع واجهة مستخدم حديثة ونظام إدارة الإعدادات المتقدم.

## ✨ المميزات

### 💼 الحاسبة المالية
- حساب الأقساط الشهرية بدقة
- تطبيق قاعدة نصف المرتب لحماية العميل
- حساب هامش الربح (عادي ومخفض)
- عرض النتائج بشكل تفصيلي ومرئي
- تحذيرات ذكية للمعاملات غير المجدية

### ⚙️ إدارة الإعدادات
- حفظ الإعدادات في ملفات JSON منفصلة
- سقف المرابحة قابل للتخصيص
- هوامش الربح قابلة للتعديل
- إعدادات التطبيق (الثيم، اللغة)

### 🚙 إدارة السيارات
- إضافة وحفظ بيانات السيارات
- استخدام سريع لبيانات السيارات المحفوظة
- حذف وتعديل السيارات
- تنظيم قاعدة بيانات السيارات

### 🎨 التصميم والواجهة
- تصميم حديث ومتجاوب
- دعم الوضع الليلي والنهاري
- خط Cairo الجميل للنصوص العربية
- رسائل تنبيه ذكية
- شاشة تحميل احترافية
- أيقونات FontAwesome

## 🛠️ التقنيات المستخدمة

- **Backend**: Node.js + Express
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **التصميم**: CSS Grid, Flexbox, CSS Variables
- **الخطوط**: Google Fonts (Cairo)
- **الأيقونات**: FontAwesome
- **تخزين البيانات**: JSON Files

## 📋 الاستخدام

### إعداد النظام
1. اضغط على زر "الإعدادات" في الشريط العلوي
2. أدخل سقف المرابحة المطلوب
3. حدد هوامش الربح (العادي والمخفض)
4. احفظ الإعدادات

### حساب التمويل
1. أدخل مرتب العميل
2. اختر مدة التمويل بالسنوات
3. حدد إذا كان هناك تخفيض
4. أدخل سعر شراء السيارة
5. أدخل سعر الإغلاق
6. اضغط "احسب التمويل"

### إدارة السيارات
1. أدخل اسم السيارة وسعرها
2. اضغط "إضافة السيارة"
3. استخدم زر "استخدم" لنقل بيانات السيارة للحاسبة
